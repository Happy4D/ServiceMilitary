# បំពេញកាតព្វកិច្ចយោធា

Static client-side website ready for GitHub and Render.

## Demo login
- Username: `admin`
- Password: `admin123`

## Deploy to Render
1. Extract this ZIP and upload all files to a GitHub repository.
2. In Render, choose **New > Static Site** and connect the repository.
3. Build Command: leave empty.
4. Publish Directory: `.`
5. Deploy.

The included `render.yaml` can also be used with Render Blueprint deployment.

## Notes
- Data and edits are stored in each browser's Local Storage.
- This demo has no server-side database or shared authentication.
